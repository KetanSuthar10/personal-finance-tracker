# Official reference index

Reviewed during planning on 17–18 October 2026. Provider facts can change; account screens establish actual entitlements. These links are reference material, not proof that any account action was performed. No exact free quota, live API success or zero-spend guarantee has been established for the owner's account.

## Antigravity

- [Model availability](https://antigravity.google/docs/models): use the actual selector; Gemini 3.8 Flash is the starting development recommendation; stronger models have plan/surface restrictions.
- [Plans and overages](https://antigravity.google/docs/plans): included quota differs by plan; AI Credit Overages can be set to Never.
- [Rules](https://antigravity.google/docs/rules): current workspace discovery includes AGENTS.md; the starter uses that direct file rather than a custom skill or complex rule framework.

## Gemini API and benefits

- [API pricing](https://ai.google.dev/gemini-api/docs/pricing).
- [Rate limits](https://ai.google.dev/gemini-api/docs/rate-limits): current project limits are shown in AI Studio; API keys in one project share project limits.
- [API keys](https://ai.google.dev/gemini-api/docs/api-key).
- [Google AI subscription plans](https://ai.google.dev/gemini-api/docs/google-ai-plans): UI subscription benefits and external API usage differ; eligible developer credits require activation/account checks.
- [Developer Program benefits](https://developers.google.com/program/plans-and-pricing): current eligible AI Pro benefit lists USD 10 monthly Cloud/GenAI credit; this owner's redemption is unverified.
- [Billing](https://ai.google.dev/gemini-api/docs/billing): paid API access and promotional-credit activation can require a purchased prepaid balance; billing signals and caps may have latency.
- [Service/data terms](https://ai.google.dev/gemini-api/terms): distinguish unpaid restrictions from paid-service handling. Masking alone does not establish permissibility.
- [Function calling](https://ai.google.dev/gemini-api/docs/function-calling) and [structured outputs](https://ai.google.dev/gemini-api/docs/structured-output): use validated schemas and a limited backend tool set.

- [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security).
- [Cloudflare Pages limits](https://developers.cloudflare.com/pages/platform/limits/).
- [Vite](https://vite.dev/guide/), [React](https://react.dev/learn/creating-a-react-app), [shadcn/ui](https://ui.shadcn.com/docs), [Recharts](https://github.com/recharts/recharts).
- [PDF.js](https://mozilla.github.io/pdf.js/), [Tesseract.js](https://github.com/naptha/tesseract.js): extraction components, not turnkey universal bank-statement parsers.
- [SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition): support varies and some browsers send audio to a service.
